# Projects

A curated list of my recent software development projects – covering APIs, full-stack applications, microservices, and data science pipelines. Each one emphasizes clean architecture, good practices, and maintainability.

### 🔹 [Orang Chat](https://github.com/OrangCorp/orang-chat)

Cloud-native, microservices-based real-time chat application built with **Java 21**, **Spring Boot**, and **Spring Cloud**.

- 💬 One-to-one and group messaging with WebSockets/STOMP
- 🔐 JWT authentication, profiles, contacts, blocking, and permissions
- 📨 Event-driven communication with **RabbitMQ**
- 🗄️ PostgreSQL persistence with Flyway migrations
- ⚡ Redis caching and session management
- 📎 MinIO object storage with asynchronous image processing
- 🔔 Web Push notifications
- 🐳 Dockerized development environment
- 🧪 Unit and integration testing with JUnit and Testcontainers

The project also includes a React frontend built with Vite and Material UI.

### 🔹 [FastAPI PostgreSQL Posts API](https://github.com/Noka993/fast-api)

REST API built with **FastAPI**, **PostgreSQL**, and **SQLAlchemy ORM**, supporting JWT-based user authentication and full CRUD operations on posts.

- ✅ Unit tests with **pytest**
- 🧬 DB migrations via **Alembic**
- 🐳 Dockerized & containerized
- 🔁 CI/CD with **GitHub Actions**

📦 **Deployed** on a local Ubuntu Server (VM).

### 🔹 [PW & Punktoza Scrapers](https://github.com/IO-Lab2/Scraper/tree/punktoza_scraper)

A set of **academic web scrapers** built with Scrapy and Playwright:

- 🕵️‍♂️ **PW Scraper** collects structured data from the Warsaw University of Technology, including scientists’ profiles, publications, and organizational structure.
- 📰 **Punktoza Scraper** collects journal titles, publishers, impact-factor points, and journal types from punktoza.pl.
- 🗃️ PostgreSQL integration for filtering and updating journal records.
- 🪄 Playwright support for JavaScript-rendered pages.

Useful for **academic data aggregation**, **analytics**, and **research management tools**.

### 🔹 [Mobile Phone Price Classification](https://github.com/Noka993/mobile-price-analysis)

🧠 A machine learning pipeline to classify mobile phones into 4 price categories based on specs.

- 🔍 Models: Logistic Regression, LDA, Random Forest, Voting Ensemble (XGBoost, KNN, etc.)
- 📊 Visualizations with SHAP & stats
- 📈 Best Accuracy: **91% (Random Forest)**  
- 🧪 Fully modular codebase with experiment-ready scripts

📄 Includes a detailed [PDF Report](https://github.com/Noka993/mobile-price-analysis/blob/main/MAD_2.pdf) (Polish).
